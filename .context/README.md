# Larity codebase context

Larity captures live meetings, streams speech to transcripts and alerts, then processes the recording into a review. The [codebase map](codebase.md) and [development guide](../docs/DEVELOPMENT.md) describe the current source and verification commands.

The [feature list](features.md) and [user flows](user-flow.md) provide product context. Older architecture, deployment, tiering, and VAD notes are historical. Use the codebase map and the linked source when those notes disagree with the implementation.
