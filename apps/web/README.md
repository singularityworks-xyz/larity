# Web Application Canvas

A clean web application canvas configured with:

- **Vite** for fast, optimized building and bundling
- **Tailwind CSS v4** for styles
- **Biome** for rapid linting and formatting

## Development

To run the development server:

```bash
bun run dev
```

To build for production:

```bash
bun run build
```

To check linting and formatting:

```bash
bun run lint
```
